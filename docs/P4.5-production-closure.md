## Security and privacy notes

- Invalid contact requests are rejected before SMTP is used; no live email was sent as part of this release UAT. Previously confirmed email delivery is **not** a substitute for a fresh authenticated SMTP end-to-end test.
- Existing public API rate limiting is per running instance (in-memory). It is **not** a global distributed rate limit. If traffic or abuse warrants it, add Vercel WAF or a shared store as a separate controlled security change.
- Production Content-Security-Policy header is currently **absent**. Add and test a robust CSP in a separate branch to avoid unexpectedly blocking Next.js scripts and trusted integrations; do not declare CSP hardened yet.
- No credentials, user data, payroll records, or authenticated enterprise dashboards were used in visual portfolio content.
- Functional checks do not validate downstream AI responses, authenticated enterprise apps, or actual SMTP delivery.

## Regression coverage

The CI workflow now runs the P4.5 regression script after the existing smoke suite. It validates localized primary routes, every product route, canonical and CreativeWork JSON-LD presence, sitemap structure and language variants, missing product 404, sample WebP asset, search/sort markup, and invalid form rejection. For actual click interactions, repeat the manual/Chrome browser UAT after major UI changes.
